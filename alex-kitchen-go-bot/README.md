# Alex Kitchen MAX Bot на Go

## Запуск

```bash
cp .env.example .env
go mod tidy
go run main.go
```

В `.env` нужно вставить токен:

```env
BOT_TOKEN=твой_токен
ADMIN_CHAT_ID=197620731
PUBLIC_CHAT_ID=-71234049717669
BROADCAST_HOUR=9
BROADCAST_MINUTE=0
```

## Что умеет бот

- кнопочное меню;
- полный каталог;
- разделы: свежее мясо, крафт, гриль, фастфуд;
- пошаговое оформление заказа;
- пересылка заявок админу;
- связь с администратором;
- ежедневная рассылка в канал/паблик;
- логирование Chat ID и User ID для настройки `.env`.

## Как узнать ID

Запусти бота и напиши ему любое сообщение. В консоли появится строка вида:

```text
message chat_id=123 user_id=456 text="..."
```

`chat_id` можно использовать как `ADMIN_CHAT_ID`.
